# 🌱 Agro Forte — Futuro Sustentável

Projeto de site desenvolvido com **HTML, CSS e JavaScript** com o tema:

> **“Agro forte, futuro sustentável: equilíbrio entre produção e meio ambiente”**

O objetivo do projeto é apresentar a importância da agricultura sustentável, mostrando como a produção agrícola pode crescer em harmonia com a preservação ambiental.

---

# 📸 Preview

O site possui:

- Banner principal com imagem de fundo
- Layout moderno e responsivo
- Seção explicativa sobre sustentabilidade
- Cards informativos
- Estatísticas animadas com JavaScript
- Design com temática ecológica

---

# 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
